# PRAMAAN - AI Assistant for Indian Standards (BIS)

## SIH Problem Statement ID: 26107

### Overview
Pramaan is a unified AI-powered assistant designed to make Indian Standards and BIS services easier to discover, understand, and navigate for MSMEs, manufacturers, and consumers.

### Features
- **AI Assistant (RAG Based):** Provides precise, verifiable information from BIS documents.
- **Voice Mode:** Real-time conversational AI voice interactions.
- **Standards Finder:** Easily search and explore mandatory (QCO) and voluntary standards.
- **Cost Estimator:** Built-in dynamic calculator incorporating MSME logic and fee concessions.
- **Certification Guide:** 6-step interactive roadmap tracking standard compliance procedures.

### Tech Stack
- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **Backend:** Node.js, Express, Prisma ORM
- **AI/ML:** Google Gemini LLM, RAG Architecture

### Installation
1. Install dependencies: \`npm install\`
2. Start the development server: \`npm run dev\`
